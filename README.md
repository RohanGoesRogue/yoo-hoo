# 🤖 AI Resume Screener

An AI-powered app to rank resumes based on how well they match a job description using BERT embeddings.

## 🔍 Features

- Upload multiple resumes (PDFs)
- Paste a job description
- Uses semantic similarity to rank resumes
- Interactive UI with Streamlit
